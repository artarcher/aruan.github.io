🎯 Цель работы[cite: 2]

Научиться применять основные операции реляционной алгебры к отношениям и записывать результат в виде нового отношения[cite: 2].

Операции реляционной алгебры[cite: 2]Выборка (σ), проекция (π), объединение (∪), пересечение (∩), разность (-), декартово произведение (×), соединение (JOIN)[cite: 2].
Организация работы[cite: 2]Записать операцию, получить результат (отфильтровать таблицу или выбрать нужные столбцы в Calc), перенести результат в отчёт[cite: 2].
💡 Главное различие[cite: 2]
  • σ выбирает строки[cite: 2];
  • π выбирает столбцы[cite: 2];
  • JOIN соединяет связанные таблицы[cite: 2].

2. Задание 1 — выборка (σ)[cite: 2]

Условие[cite: 2]
Найти всех студентов группы ИСП-21[cite: 2].

Запись реляционной алгебры: σ(ID_группы = 1) (СТУДЕНТЫ)[cite: 2]

Результат:[cite: 2]

ID_студента[cite: 2] Фамилия[cite: 2] Имя[cite: 2] ID_группы[cite: 2]
1[cite: 2] Иванов[cite: 2] Иван[cite: 2] 1[cite: 2]
2[cite: 2] Петрова[cite: 2] Анна[cite: 2] 1[cite: 2]

Дополнительное задание[cite: 2]

Найти студентов: σ(ID_группы = 2) (СТУДЕНТЫ)[cite: 2]. Студент должен самостоятельно получить Сидорова[cite: 2].

3. Задание 2 — проекция (π)[cite: 2]

Условие[cite: 2]
Получить только фамилии и идентификаторы групп студентов[cite: 2].

Запись реляционной алгебры: π (Фамилия, ID_группы) (СТУДЕНТЫ)[cite: 2]

Результат:[cite: 2]

Фамилия[cite: 2] ID_группы[cite: 2]
Иванов[cite: 2] 1[cite: 2]
Петрова[cite: 2] 1[cite: 2]
Сидоров[cite: 2] 2[cite: 2]

Задание самостоятельно[cite: 2]

Получить: π (Фамилия, Имя) (СТУДЕНТЫ)[cite: 2].

4. Задание 3 — объединение, пересечение, разность (∪, ∩, -)[cite: 2]

Для этих операций используем отдельные небольшие отношения[cite: 2].

Отношение А — студенты ИСП-21[cite: 2]:
Иванов, Петрова[cite: 2].

Отношение В — студенты, имеющие оценку 5[cite: 2]:
Иванов, Петрова, Сидоров[cite: 2].

а) Объединение[cite: 2]

A ∪ B[cite: 2]

Результат: Иванов, Петрова, Сидоров[cite: 2]. Объединение возвращает данные двух совместимых отношений[cite: 2].

б) Пересечение[cite: 2]

A ∩ B[cite: 2]

Результат: Иванов, Петрова[cite: 2]. Пересечение оставляет элементы, которые принадлежат обоим отношениям[cite: 2].

в) Разность[cite: 2]

B - A[cite: 2]

Результат: Сидоров[cite: 2]. То есть элементы В, которых нет в А[cite: 2].

Важно[cite: 2]
Для объединения, пересечения и разности отношения должны быть совместимыми по структуре (например, одинаковый тип столбца «Фамилия»)[cite: 2].

5. Задание 4 — декартово произведение (×)[cite: 2]

Берём СТУДЕНТЫ (Иванов, Петрова) и ДИСЦИПЛИНЫ (Базы данных, Математика)[cite: 2].

Выполняем: СТУДЕНТЫ × ДИСЦИПЛИНЫ[cite: 2].

Получаем:[cite: 2]

Студент[cite: 2] Дисциплина[cite: 2]
Иванов[cite: 2] Базы данных[cite: 2]
Иванов[cite: 2] Математика[cite: 2]
Петрова[cite: 2] Базы данных[cite: 2]
Петрова[cite: 2] Математика[cite: 2]
Вопрос[cite: 2]
Почему получилось 4 строки? Потому что при m строках в первом отношении и n строках во втором результат может содержать m × n строк[cite: 2].

Мини-задача[cite: 2]

Если в первой таблице 3 строки, а во второй 4 строки, сколько строк может получиться? Ответ: 3 × 4 = 12[cite: 2].

6. Задание 5 — соединение (JOIN)[cite: 2]

Условие[cite: 2]
Необходимо получить фамилии студентов и названия их групп[cite: 2].

Реляционная запись: СТУДЕНТЫ JOIN ГРУППЫ по ID_группы[cite: 2].

Результат:[cite: 2]

Фамилия[cite: 2] Группа[cite: 2]
Иванов[cite: 2] ИСП-21[cite: 2]
Петрова[cite: 2] ИСП-21[cite: 2]
Сидоров[cite: 2] ИСП-22[cite: 2]

Главная идея: JOIN позволяет получить связанную информацию, которая физически хранится в разных таблицах[cite: 2].

7. Комплексное задание[cite: 2]

Решите следующие запросы самостоятельно[cite: 2]:

  1. Задание 1: Найти студентов группы ИСП-21: σ(ID_группы = 1) (СТУДЕНТЫ)[cite: 2].
  2. Задание 2: Получить только фамилию и имя студентов: π (Фамилия, Имя) (СТУДЕНТЫ)[cite: 2].
  3. Задание 3: Получить фамилии студентов группы ИСП-21: π (Фамилия) (σ (ID_группы = 1) (СТУДЕНТЫ))[cite: 2]. (Студент впервые видит, что операции можно комбинировать[cite: 2]).
  4. Задание 4: Получить фамилию студента и название его группы: π (Фамилия, Название) (СТУДЕНТЫ JOIN ГРУППЫ)[cite: 2].
  5. Задание 5 (повышенной сложности): Получить фамилии студентов и их оценки. Необходимо использовать таблицы СТУДЕНТЫ и ОЦЕНКИ и соединить их по: СТУДЕНТЫ.ID_студента = ОЦЕНКИ.ID_студента[cite: 2].
